# TARMOQ MARKET — web do‘kon

GitHub Pages uchun tayyor, oddiy HTML/CSS/JavaScript asosidagi moslashuvchan demo sayt.

## Fayllar
- `index.html` — sayt tuzilishi
- `style.css` — dizayn va mobil moslashuv
- `script.js` — mahsulotlar, qidiruv, filtr, savatcha va demo buyurtma
- `.nojekyll` — GitHub Pages uchun

## GitHub'ga yuklash
1. GitHub'da yangi repository yarating (masalan, `tarmoq-market`).
2. Ushbu papkadagi fayllarni repository'ning asosiy (`root`) qismiga yuklang.
3. Repository → **Settings** → **Pages** bo‘limiga kiring.
4. **Deploy from a branch** ni tanlang.
5. Branch: `main`, Folder: `/ (root)` → **Save**.
6. Sayt manzili Pages bo‘limida paydo bo‘ladi. Nashr bo‘lishi bir necha daqiqa olishi mumkin.

## Muhim
Bu — frontend demo. Buyurtma va xizmat so‘rovlari hozircha faqat brauzerda tasdiqlanadi; do‘kon egasiga yuborilmaydi. Haqiqiy buyurtma qabul qilish uchun backend yoki forma xizmati, shuningdek haqiqiy telefon/manzil ma’lumotlari kerak. Aloqa bo‘limidagi telefon raqamini o‘zingizning raqamingizga almashtiring.

Mahsulot rasmlari internetdagi Unsplash rasmlaridan yuklanadi, shuning uchun rasm ko‘rinishi uchun internet kerak.
